# Редактор Presentonika

Веб-редактор презентаций, который используется внутри Presentonika. Он открывает готовые проекты, позволяет менять текст и картинки, а потом сохраняет результат обратно в WordPress или скачивает его как `out.zip`.

## Что умеет редактор

- импортировать презентации из JSON, `out.zip` и PPTX;
- редактировать текст, изображения, фигуры, таблицы и диаграммы;
- сохранять проект без потери исходных файлов;
- подбирать и заменять картинки;
- экспортировать всю презентацию или один слайд как отдельный макет;
- работать в связке с WordPress и сервисом конвертации.

## Локальный запуск

Нужен Node.js 20 или новее.

```bash
npm ci
cp .env.example .env.local
npm run dev
```

После запуска редактор будет доступен по адресу `http://localhost:3000`.

Для импорта PPTX отдельно нужен конвертер. Его адрес задаётся через `CONVERTER_URL`.

## Проверки

```bash
npm run typecheck
npm test
npm run build
```

## Docker

Перед запуском заполните обязательные переменные в `.env`, затем выполните:

```bash
docker compose up -d --build
```

По умолчанию редактор слушает только `127.0.0.1:3000`. В рабочем окружении наружу его отдаёт обратный прокси.

## Основные папки

- `app/` — страницы и серверные маршруты Next.js;
- `components/` — интерфейс редактора;
- `src/lib/` — импорт, экспорт, работа с архивами и интеграции;
- `test/` — тесты основных сценариев;
- `ops/` — файлы для запуска и наблюдения за сервисом.

Секреты и рабочие архивы презентаций в репозиторий не добавляются.
